A beautiful, interactive Mother's Day surprise built with pure **HTML, CSS & JavaScript** — no frameworks, no dependencies, just one single file!
- **Page 1 – Surprise Intro**
  Animated floating heart balloons and confetti greet you with a "Click for your Surprise!" button.
- **Page 2 – Balloon Celebration**
  180 big, shiny, realistic red foil heart balloons fill the screen. You can:
  - **Click any balloon** individually to pop it with a sparkle explosion
  - **"Pop All Balloons!"** button in the center to burst every balloon at once in a rapid-fire shower of sparkles
- **Page 3 – Heartfelt Message**
  A warm, personal Mother's Day message card to end the experience.

##  How to Use
1. Download or clone this repository
2. Open `mothers_day_heart_balloons.html` in any modern browser
3. No installation, no setup — it just works!

##  Built With
- Pure HTML5
- CSS3 (gradients, animations, filters)
- Vanilla JavaScript (DOM manipulation, SVG generation)
